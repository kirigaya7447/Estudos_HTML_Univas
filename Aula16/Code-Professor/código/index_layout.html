Perguntas frequentes

A inscrição é gratuita?

Sim. A inscrição é gratuita para estudantes e profissionais, limitada a 300 vagas.

Recebo certificado?

Sim. Participantes com frequência mínima recebem certificado de 20 horas.

Posso participar de mais de uma oficina?

Sim, desde que os horários das oficinas escolhidas não coincidam.
